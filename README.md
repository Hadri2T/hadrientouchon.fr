# hadrientouchon.fr

Mon site portfolio : présentation, expériences professionnelles, formation, projets, compétences et contact.

## Technologies

HTML, CSS et un peu de JavaScript, sans framework. Le site est hébergé avec GitHub Pages.

## Structure

```
index.html            ← page principale (français)
en/                   ← version anglaise (à venir)
assets/
├── css/style.css     ← mise en page et couleurs
├── js/main.js        ← barre du haut + neige en fond
├── img/              ← photo
└── cv/               ← CV à télécharger
```

## Voir le site en local

Ouvrir `index.html` dans un navigateur, ou lancer un petit serveur depuis le dossier du projet :

```bash
python3 -m http.server 8000
```

puis aller sur http://localhost:8000.
